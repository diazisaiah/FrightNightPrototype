# Fright Night

A first-person boxing brawler against the undead, made in Godot 4.5.

**[Play it in your browser](https://diazisaiah.github.io/FrightNightPrototype/)**. Also on itch.io.

Fight through the Underworld Arena and the Crypt, build your fighter, and take on the five champions of the Dead League.

## Repo layout
- `punch-craft/`: the Godot project.
- `GAME_DESIGN.md`: the design doc.
- `CHARACTER_BOARD.md`: future fighter ideas.
- `audio_lab/`: sound tools (the browser comparison page and the in-game Sound Lab).
- `deploy_pages.sh`: publishes the exported web build (`builds/web`) to GitHub Pages.
